## 📌 Descripción

Herramienta interactiva para calcular y generar cotizaciones profesionales de servicios en tiempo real.

Este proyecto ha sido optimizado y estructurado bajo estándares profesionales de diseño y código por **Diana Trujillo**.

## 🛠️ Instalación y Uso Local

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/Diani39ec/cotizador-pro.git
   cd cotizador-pro
   ```

2. **Ver en servidor local (Laragon / Apache)**:
   - Copia la carpeta del proyecto a tu directorio `www` en Laragon (`C:\laragon\www\cotizador-pro`).
   - Abre `http://cotizador-pro.test` en tu navegador.

3. **Para proyectos Node / React / Vue** (si aplica):
   ```bash
   npm install
   npm run dev
   ```
